BuildCraft 7.99.24.7 adapted for Minecraft Java 1.21.1 / NeoForge. Maintained by saltmoth; original mod by SpaceToad and the BuildCraft team.

This release includes the Kinetic Accumulator, modern-depth Quarry balance and metrics, demand-based Kinesis transport, modern tank/pipe integration and terrain-aware oil presentation. The Electrokinetic Transducer is an optional machine in the matching IC2 adaptation, not included in this JAR.

See the [player guide](https://github.com/saltmoth/buildcraft-1.21.1#readme) and [changelog](https://github.com/saltmoth/buildcraft-1.21.1/blob/main/CHANGELOG.md) for recipes, interfaces, connections and limits. Install the same JAR on the client and server. Java 21; release environment: NeoForge 21.1.252.
